# 认知模块 · 消化引擎使用说明

> 把抖音里「收藏了但没看」的视频，变成第二大脑「认知」模块里可直接回看的观点笔记。
> 配套工具：`workspace/tools/douyin_digest.py`（桌面 Python 伴侣程序，浏览器跑不了 Whisper 转写）。

---

## 它能做什么

抖音收藏夹是个「黑洞」——看到一半就收藏、攒一堆从没回看。这个工具把单个收藏视频：

```
抖音分享链接
  → 红狐 API 解析
      · 视频 → 下载无水印 mp4        （需 REDFOX_API_KEY）
          → 抽取音频 (wav 16k 单声道)
          → 本地 faster-whisper 转写语音为中文文稿   （免 key，模型已下到本地）
          → 抽关键帧 + 本地 RapidOCR 识别画面文字     （字幕/板书/截图文字，纯本地免 key）
          → DeepSeek 综合「语音文稿 + 画面文字」提炼
      · 图文笔记 → 下载图片 + 本地 RapidOCR 识别图片文字   （无需语音转写）
          → DeepSeek 直接以「图片文字」提炼
  → 提炼产出：核心观点3 / 结论 / 适用场景 / 领域标签 / 行动建议
  → 写入 .sync/master.json 的 learn_notes
  → 浏览器下次同步自动出现在「认知」模块 + 归档一份 Markdown
```

> **支持类型**：抖音**视频**与**图文笔记**。图文笔记（链接含 `/note/`）自动走图片 OCR 链路，跳过语音转写；若红狐接口未返回图片地址则提示「暂无法自动消化」，此时可手动复制图文文字 → 编辑已有素材粘贴进去。

**来源标识 + 自动去重**（2026-08-05 新增）：消化时从红狐返回的元数据里抽取**博主昵称、发布日期、作品唯一 ID**，写入笔记并在卡片上展示（`@博主` 粉色标签 + `📅 发布日期`）；同时以「作品唯一 ID → 规范化链接 → 你提交的原始链接」三层比对**已消化过的作品**，命中则直接跳过并提示「已消化过（来源：@博主 · 日期），已跳过重复」，避免同一个收藏视频被反复消化。旧笔记（升级前入库、无作品 ID）也能凭「同一条原始链接」命中去重。

- 卡片来源展示：引擎消化的笔记会显示 `@博主` 与 `📅 发布日期`；手动添加的笔记这两项为空、不显示。
- 去重是**后端 server.py 触发时**执行（脚本在下载/转写前先查重），前端会区分「✅ 已消化」与「⚠️ 已消化过（跳过）」两种提示。

**价值在"处理"不在"存储"**：进来一条就消化一条，逼自己清积压。

## 前置准备（只需配一次）

1. **虚拟环境**：`douyin` venv 已装 `faster-whisper / openai / requests / imageio-ffmpeg / opencv-python-headless / rapidocr-onnxruntime`。
   路径：`C:/Users/Lenovo/.workbuddy/binaries/python/envs/douyin/Scripts/python.exe`

2. **本地转写模型**：`faster-whisper-base` 已从 ModelScope 下到
   `workspace/models/faster-whisper-base/`（含 `model.bin` 等 4 个文件，约 142MB）。
   脚本检测到该目录即优先用本地模型，**不再走 HuggingFace**（国内拉 HF/Xet 权重会失败）。

3. **密钥（放 `workspace/.env`，已被 .gitignore 排除，不进仓库/聊天）**：

   ```ini
   REDFOX_API_KEY=你的红狐key        # 下载视频必须
   OPENAI_BASE_URL=https://api.deepseek.com
   OPENAI_API_KEY=你的deepseek_key   # 分析必须
   OPENAI_MODEL=deepseek-chat
   ```

## 用法

### 方式 A · 页面内一键消化（推荐，日常用这个）⭐

打开工作台「认知」模块，点顶部 **🤖 粘贴抖音/视频链接，一键智能消化** 按钮（或在「+ 添加」弹窗里粘贴视频链接，输入框下方会自动出现「🤖 智能消化」按钮）。粘贴抖音分享链接 → 点消化 → 页面显示进度（约 30–90 秒）→ 自动同步并出现在「待消化」。

**前置（只需一次）**：本机必须运行**新版** `server.py`（含 `/api/digest` 接口），且浏览器「设置 → 后端服务地址」指向它：
- 本机直接打开 `http://localhost:8080` → 不用设后端地址；
- 用部署版页面（CloudStudio 等）→ 把后端地址设成本机 `server.py` 的 cloudflared 隧道 https 地址，页面才能回连本机跑转写。

> 云端部署页本身是纯静态、不跑转写；消化管线（venv + 模型 + .env 密钥）只在本机，所以必须本机 server.py 在线。

### 方式 B · 命令行（给我/自己跑脚本，适合批量或调试）

#### 单条

```bash
cd G:/_06_项目代码/工作台/workspace
HF_HUB_DISABLE_XET=1 "C:/Users/Lenovo/.workbuddy/binaries/python/envs/douyin/Scripts/python.exe" ^
  tools/douyin_digest.py --url "https://v.douyin.com/xxxx/"
```

- 脚本会自动读 `workspace/.env`，不用手动 `set` 任何东西。
- `HF_HUB_DISABLE_XET=1` 是保险项（本地模型已绕过 HF，可省略，但留着无害）。

### 批量（消化整列收藏）⭐

把一堆抖音链接**每行一个**写进文本文件（链接从抖音「分享 → 复制链接」得到）：

```txt
https://v.douyin.com/9O-Wyv6LUUo/
https://v.douyin.com/vP6Tsc3tD80/
https://v.douyin.com/LihkZhmwOMA/
```

然后一条命令串行处理：

```bash
cd G:/_06_项目代码/工作台/workspace
"C:/Users/Lenovo/.workbuddy/binaries/python/envs/douyin/Scripts/python.exe" ^
  tools/douyin_digest.py --batch-urls-file urls.txt
```

可选：把失败的链接单独记到一个文件，方便二次补跑：

```bash
tools/douyin_digest.py --batch-urls-file urls.txt --fail-log failed.txt
```

**批量行为**：串行逐条处理；某条失败（下载/转写/分析任一环节报错）**不会中断**整个流程，会跳过继续下一条；最后打印 `批量完成：成功 N 条 / 失败 M 条` 并列出失败明细。

### 其它测试开关

| 参数 | 用途 |
|------|------|
| `--file "C:/videos/xxx.mp4"` | 直接用本机已下载的视频，跳过下载 |
| `--transcript-file t.txt --skip-download --skip-llm` | 仅验证「写库+归档」，用给定文稿，无需任何 key |
| `--skip-llm` | 只跑到转写，不调 DeepSeek（验证本地转写链路） |

## 注意事项 / 已踩坑

1. **日志不实时刷新是正常的**：Python 把 stdout 块缓冲（重定向到文件时非行缓冲），
   中途看不到进度。判断进度最可靠的方式是看 `data/learn-digests/` 目录——每完成一条就落盘一个文件。
   想实时看日志可加 `-u` 运行：`python -u tools/douyin_digest.py --batch-urls-file urls.txt`。

2. **本地模型优先**：只要 `workspace/models/faster-whisper-base/model.bin` 存在，转写就走本地、免 key。
   不要删这个目录，也不要设 `HF_ENDPOINT` 去远端拉——该模型在 HF 上已改用 Xet 存储，国内镜像拉不到真实权重。

3. **转写稿有同音 ASR 误差**（如「负反馈→司法会」「迭代→叠带」），但不影响 DeepSeek 提炼的观点质量。

4. **密钥安全**：`REDFOX_API_KEY` / `OPENAI_API_KEY` 只放在 `workspace/.env`，切勿再发到聊天。
   若曾在聊天里贴过，建议去对应后台轮换一次。

5. **抖音收藏夹本身读不到**：收藏是私人登录数据，工具只能靠你「分享→复制链接」手动喂单条链接，
   无法幻想整列自动同步。批量模式就是用来一次性消化你手动贴出来的整列链接。

# 安卓「零摩擦消化」配置说明

## 关键认知：抖音 App 不暴露系统分享表
抖音 Android 客户端的「分享」面板**只调自己的好友/站内渠道，不调安卓系统分享表（Sharesheet）**。因此 PWA 的 `Web Share Target` **不会出现在抖音的分享面板里**（浏览器、微信等调起系统分享表的 App 仍正常出现）。

所以「从抖音分享面板选第二大脑」这条路在抖音里走不通。改用下方「长按图标 → 消化剪贴板」方案，一样零摩擦，且不依赖抖音配合。

## 方案：长按图标「消化剪贴板链接」（推荐，已上线）
利用 PWA 的 **应用快捷方式（App Shortcuts）**，在桌面图标上长按即可唤起一个专属入口，自动读剪贴板里的抖音链接并提交消化。

> 为什么不监听剪贴板后台吞链接？因为分不清你是要「消化」还是「发给朋友」，会把发给哥们的视频也塞进待消化。而「复制链接」这个动作本身意图就是「拿去别处用」，由你主动长按图标触发，干净不误伤。

## 前提（必须满足）
1. **电脑上 `server.py` 正在运行**——消化管线全部在本机跑（本地 Whisper 转写 + RapidOCR + DeepSeek 提炼），手机只负责「触发」。
2. **手机能访问你电脑的 server.py**，二选一：
   - 同一 WiFi：填电脑局域网 IP，如 `http://192.168.1.50:8080`
   - 外网：用 cloudflared 隧道地址（`./tunnel.sh named` 得到的固定地址）
3. **手机端「第二大脑」已填「后端服务地址」**：打开手机端第二大脑 → 设置 → 后端服务地址 → 填上面的地址 → 保存

## 安装「第二大脑」到主屏幕（只需一次）
1. 手机 Chrome 打开：`https://56262585fbc44d088ae9a314cdab645f.gz3.agentos-app.net`
2. 点右上 `⋮` → **「添加到主屏幕」** → 名称「第二大脑」→ 添加
3. 桌面出现「第二大脑」图标，即为已安装 PWA（自动带快捷方式能力）

## 日常用法（零摩擦，绕过抖音分享面板）
1. 抖音里看到想消化的视频 → 点「分享」→ **「复制链接」**（注意是复制链接，不是发给好友）
2. 回到手机桌面 → **长按「第二大脑」图标** → 弹出菜单选 **「消化剪贴板」**
3. 自动读取剪贴板链接 → 点一下 **「🤖 消化」** → 显示「✅ 已提交消化」
4. 回到「第二大脑」App → 认知 · 待消化 查看结果（约 30–90 秒）

## 备选入口
- **系统分享（浏览器/微信等）**：这些 App 调起系统分享表时，「第二大脑」仍会出现在分享目标里，点一下直接消化。
- **手动粘贴兜底**：直接打开 `share.html`（或桌面图标），在文本框粘贴抖音分享文案，点「🤖 消化」。
- **HTTP Request Shortcuts（开源，F-Droid）**：若不愿装 PWA，可建一个 Share 触发的 Shortcut，POST `{shared_text}` 到 `/api/digest`。

## 实现位置（给维护者）
- `manifest.webmanifest`：含 `share_target`（系统分享用）+ `shortcuts`（长按图标「消化剪贴板」→ `./share.html?mode=clipboard`）
- `sw.js`：最小**透传** Service Worker，只满足 PWA 安装要求，不做缓存（避免「缓存导致看不到更新」坑）
- `share.html`：接收页，三入口统一——系统分享参数 / `?mode=clipboard` 读剪贴板 / 手动粘贴；读 `localStorage.sb_api_base` → POST `/api/digest`
- `index.html`：静态 manifest 引用 + 注册 SW
- 后端 `/api/digest` 已支持 JSON、`Access-Control-Allow-Origin: *`，跨域回连无碍

## 注意事项
- ⚠️ **CloudStudio 每次重部署会新建工作区、可能换 URL**。若部署地址变了，需重新「添加到主屏幕」（旧图标指向旧工作区）。长期建议绑固定域名或迁 GitHub Pages（见 `docs/稳定部署方案.md`）。
- 消化结果存在电脑本机 IndexedDB，手机端经同步拉取；隧道/局域网断开时手机看不到最新结果。
- **iOS 不支持 Web Share Target / App Shortcuts**，iPhone 用户需改用「快捷指令」（Shortcuts）注册分享扩展，另配。
